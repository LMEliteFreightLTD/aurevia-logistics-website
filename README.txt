AUREVIA LOGISTICS LTD WEBSITE

FILES
- index.html: website content
- style.css: colours, layout and responsive design
- script.js: mobile navigation and copyright year
- assets/aurevia-banner.png: your supplied banner image

PREVIEW
1. Keep the files in this folder structure.
2. Open index.html in your browser.

BEFORE PUBLISHING
1. In index.html, replace YOUR-EMAIL@example.com with the company's real email address.
2. Review the service and company descriptions so they accurately describe the business.
3. You may replace the banner image in assets, but keep the filename aurevia-banner.png.

FREE PUBLISHING WITH GITHUB PAGES
1. Create/sign in to a GitHub account.
2. Create a new PUBLIC repository, e.g. aurevia-logistics-website.
3. Upload the contents of this folder, including the assets folder.
4. In the repository, open Settings > Pages.
5. Under Build and deployment choose Deploy from a branch.
6. Select branch main and folder /(root), then Save.
7. Wait for the published link to appear in the Pages section.

The website is static HTML/CSS/JavaScript. No paid hosting is required. A custom domain is optional and usually costs money.
